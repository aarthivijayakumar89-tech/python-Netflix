# Netflix Data Analysis & Recommendation System

**Course Project:** MA522M (Feb 2026 – Mar 2026)

This project analyzes the Netflix dataset using Python to understand trends in movies and TV shows. It also includes a simple recommendation system that suggests content based on user preferences.

## Features
- Analyzed over 18,000 Netflix records
- Cleaned and preprocessed the dataset
- Performed Exploratory Data Analysis (EDA)
- Visualized trends in genres, ratings, and content distribution
- Developed a simple movie recommendation system
- Generated graphs and charts to present insights

## Technologies Used
- Python
- Pandas
- Matplotlib
- GeoPandas

## How to Run
1. Install the required libraries:

```bash
pip install pandas matplotlib geopandas
```
2. Open `Project_MA25M017.ipynb` in Jupyter Notebook or Google Colab.
3. Make sure the dataset file is in the same folder as the notebook.
4. Run all the cells in order.

## Project Workflow
1. Load the Netflix dataset
2. Clean and preprocess the data
3. Perform exploratory data analysis
4. Create visualizations
5. Generate movie recommendations
